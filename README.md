## 📌 Sobre esta versão

Esta é a versão **Angular** do portfólio — desenvolvida com Angular 19, TailwindCSS e `ngx-translate` para internacionalização.

É **100% aberta para a comunidade**. Faz um fork, adapta para o teu perfil e usa como quiser. Só peço que dê uma ⭐ se te ajudou!

## ✨ Funcionalidades

- 🌍 **Internacionalização** — suporte a PT-BR, EN e ES via `ngx-translate`
- 🌙 **Tema escuro/claro** — alternância com persistência no `localStorage`
- 📱 **Responsivo** — adaptado para mobile, tablet e desktop
- ⚡ **Scroll suave** — navegação entre seções com offset do header fixo
- 📬 **Formulário de contato** — campos validados com feedback visual
- 🔀 **Seletor de versão** — alterna entre as versões React, Angular e Thymeleaf
- 🎞️ **Animações** — entrada de elementos com `@angular/animations`

## 🍴 Usando como template

**1. Faz o fork**

Clica em **Fork** no canto superior direito e seleciona a branch `angular`.

**2. Clona o teu fork**

```bash
git clone -b angular https://github.com/SEU_USUARIO/portfolio.git
cd portfolio
```

**3. Instala as dependências**

```bash
npm install
```

**4. Personaliza o conteúdo**

Os principais arquivos para editar são:

```
src/
├── assets/
│   └── i18n/
│       ├── pt.json   # Textos em Português
│       ├── en.json   # Textos em Inglês
│       └── es.json   # Textos em Espanhol
└── app/
    └── components/
        └── header/
            └── header.ts   # Atualiza links de versão e redes sociais
```

**5. Roda localmente**

```bash
npm start
```

Acesse em `http://localhost:4200`

**6. Faz o deploy**

Recomendo a [Vercel](https://vercel.com) — conecta o repositório, seleciona a branch `angular` e o deploy é automático a cada push.
